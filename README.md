# Что находится в этом репозитории
Этот репозиторий- мое портфолио по 3d-печати.  
У меня принтер - **CREALITY Ender 3 V3 SE**.  
Мне интересне самому спроектировать деталь, создать чертеж по готовой детеали (реинжиниринг), а не просто скачать модель с интеренета и распечатать.


Каждый проект имеет:описание и ссылку для скачивания архива с файлами.  
В каждом архиве размещены:
* файл детали созданный в "Компас 3D";
* файл с 3d моделью;
* файл-gcode. (для моего принтера)

# Заглушка для сервера.
Меня попросили найти заглушкb для открытого отверстия сервера. Имелся только чертеж самой заглушки.  
Тут будет чертеж. 
Поскольку в пределах России я нашел только в одном месте и то на заказ, и то по предоплате и главное цена одной чуть ли не половина стоимости моего 3D-принтера. А нужно было 6 таких заглушек. Поэтому я просто сделал модель и распечатал ее.  
Отличия от оригинала:  
* из-за маленького размера стола принтера, модель пришлось разделить на две части, плаировалось потом склеить. Никаких проблем, даже не склееная заглушка встала как родная. 😄
* крепежные отверстия по бокам указаны с резьбой, в модели решили делать отверстие без резьбы так как на таком маленьком диаметре оно все-равно хорошо не получится, лучше метчиком, да и крепление подразумевает, что болт крепится к корпусу и тем самым держит заглушку.
